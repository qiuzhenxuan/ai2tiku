# 毛笔无限 · 视觉资源

标志采用手绘毛笔的无限回环，保留笔锋、飞白、粗细变化与轻微不对称。桌面图标和应用内部使用同一张图，避免重新描摹导致形状不一致。

原图由内置图像工具生成，使用描述见 [logo-prompt.txt](logo-prompt.txt)。

- `src/assets/brand/infinity-brush.png`：带透明通道的毛笔标志原图。原生界面嵌入图像，在深色模式反转墨色并保留透明度。
- `src-tauri/icons/`：同一毛笔图像加上白纸圆角底板后生成的 PNG、ICO、ICNS 与 Windows 图标。
- `src/assets/brand/favicon.png`：旧 WebView 兼容入口的小尺寸图标。
- `src-tauri/src/native/widgets.rs`：灰阶色板、卡片、按钮、字段、表格列与间距。
- `src-tauri/src/native/paint.rs`：静态淡墨背景、纸张纤维与侧栏图标动效；不在文字和表格上覆盖图像。

原生界面默认使用 72px 图标侧栏，点击顶部切换按钮展开为 200px 文字侧栏；两种状态的 Logo、切换按钮和图标保持对齐，每次启动默认折叠。内容边距为 24px，常规操作按钮与单行表单控件统一 34px 高、6px 圆角，短操作按钮最小宽度 64px；只读信息行使用较紧凑的间距，编辑弹窗保留 20px 内边距。标题、正文和辅助说明分层。宽度较小时，概览统计块与服务信息分行排列。默认黑白配色；日夜与减少动态效果偏好写入原本的本地数据库。

悬停通过墨色、边框和底色反馈，不改变控件大小；按下和键盘聚焦有独立状态。可点击控件显示手型，文本输入保留文字光标，禁用控件保持静态。火箭尾焰由连续喷流和细颗粒组成，采用灰阶绘制并在导航行内向下扩散；减少动态效果时关闭。

重新生成应用图标：

```powershell
./scripts/prepare-brand.ps1
```

脚本保留毛笔原图，仅通过 SVG 底板封装并使用 Tauri 图标工具导出各尺寸。Tauri CLI 仅作为图标导出工具；原生程序的正常构建和运行不需要 Tauri CLI、Node 或 pnpm。
