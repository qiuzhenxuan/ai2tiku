# 题库与诊断工具

## 备份、恢复与导入

在「题库管理」顶部使用「备份 / 导出」选择保存位置。导出的是整个题库，不受搜索词、来源筛选和分页影响。JSON 包含题干、完整选项、题型、答案、题目来源、模型名称、命中次数和时间；不包含供应商配置、API Key、应用设置、答题记录或原始图片。

「导入 / 恢复」选择 UTF-8 JSON 后先显示预览：新题、已有重复题、答案冲突、文件内部重复和无效条目。文件最大 50MB、100000 道题。导出也检查同一限制，避免生成无法恢复的备份。

- **合并导入**：仅添加新题，不修改已有题目。题干、题型和完整选项一致时视为同题，允许选项乱序；按选项正文比较实际答案。已有重复和冲突均跳过。同文件内重复的新题只导入第一条。
- **恢复整个题库**：使用文件替换全部题目。执行前自动把当前题库保存到数据目录的 `backups/before-restore-日期时间.json`；界面显示备份路径。可以再次选择这份备份恢复。供应商、设置与答题记录保持不变。

预览后题库内容发生变化时会要求重新预览。校验失败不会写入部分题目；备份失败会阻止恢复；恢复使用 SQLite 事务，写入失败会回滚。AI 请求在恢复完成后产生的新缓存仍可正常入库。

版本化备份保留历史题目的原始答案及重复行，方便完整恢复。若备份本身含有冲突，预览会提示；这不代表这些答案已经过人工确认。外部题目数组会按题型校验答案，出现无效条目时整次导入被阻止。

除本软件的版本化备份外，也支持以下题目数组：

```json
[
  {
    "title": "1 + 1 = ?",
    "options": ["A. 1", "B. 2", "C. 3", "D. 4"],
    "qtype": "single",
    "answer": "B"
  },
  {
    "title": "请选择偶数",
    "options": "A. 2\nB. 3\nC. 4",
    "qtype": "multiple",
    "answer": ["A", "C"]
  }
]
```

题型支持 `single`、`multiple`、`judgement`、`completion`、`unknown`；`type` 可作为 `qtype` 的别名。未知题型不会被自动作答缓存匹配直接复用。当前不支持 CSV、Excel 或任意其他题库文件格式。

## 失败记录与实时更新

记录覆盖空题目、本地未命中且关闭 AI、无可用模型、配置/查询异常、网络与供应商错误、答案校验失败和无效 HTTP 请求。每个已完成搜题请求写一条记录；同一次请求内的 AI 格式重试合并在该记录中，用量按上游已返回的数据累计。

点击题库或记录中的题干，可在右侧抽屉查看完整题干、选项、答案、解析、失败原因、模型、耗时和 Token。图片题仅记录图片张数，不保存图片原始内容。旧版已遗漏的失败请求无法补回；已有旧记录的空答案标记为失败，并注明旧版未保存详情。

答题成功率为成功请求数 / 全部已记录请求数，缓存命中率为缓存命中数 / 全部已记录请求数。AI 请求次数按使用 AI 的搜题请求计数，包含失败，内部重试不会增加搜题请求数。没有返回用量的失败请求不能据此认定没有扣费。数据库无法写入时会返回记录保存失败提示，并保留有效答案。

概览、答题记录、统计与题库页面在窗口可见时约每秒检查一次数据版本，有变化才重新加载；后台暂停，返回窗口立即刷新。刷新失败会重试，不推进已处理版本；安静更新不重复弹出错误通知。

## 一键诊断

概览的「一键诊断」进入设置并检查数据库读取、本地 HTTP 接口、AI 兜底状态、网络方式和当前实际选中的模型配置。默认不访问模型服务、不消耗模型 Token；软件无法直接读取浏览器扩展内部权限，因此不会声称已验证脚本猫/OCS 内部状态。

「模型调用检查…」会先弹出应用内确认框，再向所选模型发送简单诊断题。可能产生 Token 费用，30 秒未完成时提示超时；上游可能继续处理并计费。诊断结果不写入题库或答题统计。

删除、清空、恢复和模型调用检查统一使用应用内确认框。支持取消、Esc、Tab 焦点约束和关闭后焦点返回；破坏性操作默认聚焦取消按钮。
