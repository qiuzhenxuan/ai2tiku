# 网页端验证记录

本项目网页端已在单机 Linux、Docker Compose 和 HTTPS 反向代理环境部署。以下明确区分本轮隔离测试与生产验证，实际模型作答另行验证。

## 已通过

- Rust 服务可在不启用桌面功能的情况下独立编译。
- `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --features hosted --locked --offline --lib`：74 个测试通过，覆盖权限、登录与注册会话凭据版本、来源隔离限流及容量淘汰、供应商地址绑定、异常记录及图片数组边界。
- 网页端 Vue/TypeScript 类型检查与 Vite 生产构建。
- `scripts/check-hosted.cjs` 使用真实 Rust 服务及生产前端，在隔离临时目录运行；仅第三方模型元数据端点由浏览器固定数据替代，模型列表 HTTP 读取另由 Rust 本地模拟供应商覆盖：
  - 管理员和用户登录、普通用户访问后台被拒绝、关闭注册时无法自行注册。
  - 不同来源的浏览器写操作被拒绝。
  - 模型 Key 保存后输入框清空，接口不回显，数据库及 WAL 中没有其明文。
  - 填 Key 自动读取模型并显示下拉框，选择的实际模型名称正确保存，不通过预设冒充供应商列表。
  - `/api/search?t=…` 的未登录 HEAD／GET 返回 200；HEAD 没有响应体，GET 不返回答案、不消耗额度；POST 搜题仍需令牌。
  - 生成的 OCS 配置使用 Bearer 题库令牌，不含模型 Key。
  - 令牌弹窗必须确认已保存后关闭；关闭并刷新后无法读取完整令牌。
  - A 用户不能删除 B 用户的令牌；用户请求记录相互隔离。
  - 请求额度生效；管理员撤销令牌后立即失效；停用账号后已有会话失效。
  - 将额度改为 0 后可继续请求且保留已用次数；界面显示“无上限”，不显示无效的零上限进度条。
  - 登录页和站内顶部 GitHub 按钮链接到项目仓库，并使用新标签页。
  - 管理后台在 1280、900 和 390 像素宽度下无整页横向溢出。
  - 浏览器无运行错误，没有生成截图。
- 安全回归额外验证：重置或停用后的旧凭据版本无法生成会话；不同来源限流互不影响；未启用代理信任时忽略伪造转发头；目标地址变化的 Key 不能用于保存、发现、令牌创建或模型调用；旧 custom-N 不做地址猜测迁移。
- 真实本地 HTTP 发送 7 MiB 非法题型后，只落库固定 `unknown`，列表不返回原字段；SQL 读取旧异常记录在分配前限长，桌面完整读取行为保留。
- Compose YAML 语法解析，初始化脚本和验证脚本的 Node 语法检查。

测试仅使用随机测试密码和无效的模型 Key。所有搜题请求都在题干校验阶段返回，没有访问模型供应商或产生模型费用；测试结束停止服务并删除本轮独立的临时数据目录。

## 验证边界

本机未安装 Docker；Linux 镜像构建与容器入口检查由 GitHub Actions 执行，具体结果以对应提交的运行记录为准。生产部署需核对镜像提交、保留数据卷与加密主密钥，并验证 HTTPS 入口。

已配置生产服务器、IP HTTPS 证书与自动续期；没有用真实供应商 Key 验证付费模型作答。OCS 配置结构复用原有声明方式并加入鉴权头；真实 OCS 浏览器脚本到公网模型作答的完整链路，仍需用户用自己的测试题验证。

## 首版范围

- 单机 SQLite，适合先部署在一台服务器。不要同时启动多个 API 实例共享同一个数据库目录。
- API 全局并发上限 32，每用户 2；每用户最多 10 个有效题库令牌。
- 登录与注册按实际来源、来源与邮箱组合限速，密码校验另有并发保护。公网 Nginx 按真实客户端地址限制入口；受控代理信任需要按部署说明显式配置。
- 每日请求额度按 UTC 00:00（北京时间 08:00）重置，不代表模型供应商余额或金额上限。
- 管理用户列表最多返回 10000 个账户；审计页面保留最近 200 条展示，底层记录仍在数据库中。
- 网页端首版提供题库和记录查看、接入管理、用户管理；桌面版的导入导出与诊断界面没有直接暴露到公网。
