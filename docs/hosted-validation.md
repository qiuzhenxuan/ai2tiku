# 网页端验证记录

本次交付为可自托管源码与 Docker 部署文件，不表示已经部署到公网服务器。

## 已通过

- Rust 服务可在不启用桌面功能的情况下独立编译。
- `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --features hosted --locked --offline --lib`：54 个测试通过，其中 10 个为新增多用户服务测试。
- 网页端 Vue/TypeScript 类型检查与 Vite 生产构建。
- `scripts/check-hosted.cjs` 使用真实 Rust 服务及生产前端，在隔离临时目录运行，无模拟后端：
  - 管理员和用户登录、普通用户访问后台被拒绝、关闭注册时无法自行注册。
  - 不同来源的浏览器写操作被拒绝。
  - 模型 Key 保存后输入框清空，接口不回显，数据库及 WAL 中没有其明文。
  - 生成的 OCS 配置使用 Bearer 题库令牌，不含模型 Key。
  - 令牌弹窗必须确认已保存后关闭；关闭并刷新后无法读取完整令牌。
  - A 用户不能删除 B 用户的令牌；用户请求记录相互隔离。
  - 请求额度生效；管理员撤销令牌后立即失效；停用账号后已有会话失效。
  - 登录页和站内顶部 GitHub 按钮链接到项目仓库，并使用新标签页。
  - 管理后台在 1280、900 和 390 像素宽度下无整页横向溢出。
  - 浏览器无运行错误，没有生成截图。
- Compose YAML 语法解析，初始化脚本和验证脚本的 Node 语法检查。

测试仅使用随机测试密码和无效的模型 Key。所有搜题请求都在题干校验阶段返回，没有访问模型供应商或产生模型费用；测试结束停止服务并删除本轮独立的临时数据目录。

## 验证边界

本机未安装 Docker，未在本机运行容器或 Nginx 配置检查。仓库检查流程新增 Linux 上的多用户测试与 Docker 镜像构建，具体结果以对应提交的 GitHub Actions 为准。

尚未连接站长的服务器、配置域名/TLS，或使用真实供应商 Key 验证模型作答。OCS 配置结构复用原有声明方式并加入鉴权头；真实 OCS 浏览器脚本到公网服务的完整链路，需要部署后用自己的测试题再验证。

## 首版范围

- 单机 SQLite，适合先部署在一台服务器。不要同时启动多个 API 实例共享同一个数据库目录。
- API 全局并发上限 32，每用户 2；每用户最多 10 个有效题库令牌。
- 登录与注册存在服务总量和单邮箱限速。Nginx 再限制登录请求；外部代理可能让多个用户共享入口限速。扩大用户量前应按真实代理拓扑调整可信来源和限速。
- 每日请求额度按 UTC 00:00（北京时间 08:00）重置，不代表模型供应商余额或金额上限。
- 管理用户列表最多返回 10000 个账户；审计页面保留最近 200 条展示，底层记录仍在数据库中。
- 网页端首版提供题库和记录查看、接入管理、用户管理；桌面版的导入导出与诊断界面没有直接暴露到公网。
