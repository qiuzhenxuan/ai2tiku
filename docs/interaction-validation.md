# 图标交互与动画验证

本轮针对 WebView 界面，不涉及 Rust 答案与存储逻辑，也未发布新的 Release。

## 已完成

- 八个导航图标：悬停、键盘聚焦、移开复位、图标按钮位置稳定；插头、数据库与列表的缩放原点在进入和退出时一致。
- 提示卡片：点击导航后收起；鼠标停在其他导航项时，方向键聚焦的项目仍能显示对应说明；Esc 可收起，重新移动鼠标可以切回鼠标交互。
- 已选中导航：日间、夜间均有独立悬停和按下背景反馈。
- 火箭：72 个粒子；移开后继续当前飞行而不重新喷射，最长 560ms 后全部暂停；快速重新悬停恢复所有粒子；页面隐藏时暂停。
- 供应商、模型的四个纯图标按钮：34×34，有操作名称和悬停提示。
- 弹窗、详情抽屉：220ms 进入、160ms 退出；退出期间不接收点击和键盘操作；背景及时解除锁定，焦点返回原控件；支持关闭后立即重开。
- 嵌套确认框：按打开层级显示，恢复确认按钮可以点击，取消后焦点回到预览。
- 减少动态效果：禁用 CSS 动画与过渡延迟，覆盖状态脉动、Toast、自测结果及加载旋转；弹窗不缩放，火箭不喷射。
- OCS 自测结果：补齐进入关键帧，加载时使用刷新图标并显示“搜索中…”。

## 验证方式

- `pnpm build`：类型检查和生产构建通过。
- `scripts/check-interactions.cjs`：新增交互专项检查，通过，无截图输出。
- `scripts/check-webview.cjs`：八页、两种主题、两种侧栏状态、两种窗口尺寸，以及侧栏反向过渡、方向提示、控件尺寸、右键阻止和火箭状态检查通过。
- `scripts/check-data-features.cjs`：实时刷新、详情、焦点约束与恢复、嵌套确认、导入恢复和诊断回归通过。

浏览器为无界面 Edge，后端调用全部使用隔离模拟数据。没有启动桌面程序、调用系统文件对话框、访问用户数据库或付费模型。原有验证脚本生成的临时截图在结束后自动清除；新增脚本只保存小型 JSON 结果。

这些结果验证前端逻辑与浏览器行为，不代表实际桌面 WebView2 在所有显卡上的帧率保证。
