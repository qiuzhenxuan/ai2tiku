# Rust 原生界面迁移

默认入口为 egui/eframe 桌面窗口。原有 `db`、`answers`、`ai`、`search`、`server` 模块直接复用；界面不通过 JavaScript IPC 调用业务。Tauri 与插件依赖改为可选，仅在显式启用 `webview` 时编译。

| 页面 | 原生功能 |
| --- | --- |
| 概览 | 统计、启停服务、最近搜题、模型分布 |
| 部署向导 | 五步引导、Edge 定向打开、权限图解、版本查询 |
| OCS 接入 | 服务状态、完整 JSON 复制、本地搜题自测 |
| 供应商与模型 | 预设、增删改、读取模型、连通测试、默认模型 |
| 本地题库 | 关键词与来源筛选、分页、增删改、清空全库确认 |
| 答题记录 | 来源、答案、模型、耗时、分页与清空确认 |
| 用量统计 | 请求与 Token 趋势、缓存命中、模型分布 |
| 设置 | 端口、代理、缓存、AI 兜底、提示词、日夜与减少动效 |

Windows 继续使用 `%APPDATA%/com.ai2tiku.app/ai2tiku.db`，不另建空库或复制覆盖旧库。升级前请退出旧版，避免两套程序占用相同本地端口。

网络、模型调用与数据库快照在后台任务运行，通过消息接收结果；等待期间仍能切换页面。任务按操作类型防止重复触发，快照按版本号丢弃过时结果；保存失败保留表单。复制前重新检查服务和端口，等待系统剪贴板实际写入结果。

原生窗口读取系统中文字体，楷体可用时用于标题，不分发 Windows 字体。窗口最小尺寸 900 × 600。动效位于导航图标内部，火箭竖直升空、喷口随动、粒子向下，减少动态效果时关闭。

侧栏每次启动默认折叠为 72px 图标栏，点击顶部按钮展开为 200px 文字栏；切换按钮也可用键盘激活。Logo 和图标的位置保持稳定。侧栏可用 Tab 聚焦，上下方向键在八项中循环，Home / End 跳至首尾，Enter / Space 进入页面。聚焦会显示页面说明，Escape 收起说明并保留当前焦点；移开或切换焦点后可以再次展开。图标内部错峰展开，按下时轻微收缩；减少动态效果时保留静态高亮。

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --locked --lib
cargo build --manifest-path src-tauri/Cargo.toml --release --locked
```

可用 `--data-dir ./local-test-data` 指定独立数据目录。原生帧缓冲冒烟验证：

```powershell
./src-tauri/target/release/ai2tiku.exe --smoke-test ./native-captures
python scripts/check-native.py ./native-captures
```

冒烟模式使用独立演示数据库和临时回环端口，依次截取折叠状态的 8 页日间、8 页夜间、8 页最小窗口及 4 个编辑 / 确认弹窗，再检查 8 个导航图标的静止、悬停、复位和键盘聚焦，以及减少动效；另截取展开状态的 8 页、夜间概览和最小窗口，共 71 张。

动效检查向当前原生窗口注入测试输入，不移动系统鼠标；等待真实动画时长后记录截图、按钮边界与动画进度。火箭悬停和键盘聚焦各采集三秒帧间隔，记录平均帧率、中位帧时、95 分位帧时和长帧。火箭另有绘制几何测试，核对竖直位移、喷口随动、连续喷流、向下粒子与复位。测试不读取用户 Key、不访问真实模型，结束后关闭自己的服务。

截图检查脚本需要 Pillow。侧栏按键路径另由 Rust 测试发送实际 `Key` 事件验证，覆盖上下循环、首尾跳转、Enter / Space 激活以及 Escape 收起说明。截图中直接设置焦点的检查只用于动画终态，不代替按键路径验证。
