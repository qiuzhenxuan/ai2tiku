# 0.2.0 本地原生版验证

2026-10-22，在 Windows、150% DPI 环境中验证当时工作区的 0.2.0 Rust 原生 Release。后续动效与侧栏改进见 [0.2.1 验证记录](native-validation-0.2.1.md)。界面使用 egui/eframe + Glow，测试窗口直接输出原生帧缓冲截图。

| --- | --- |

| Rust 测试 | 34 项全部通过 |
| 页面与布局 | 8 页日间、8 页夜间、8 页最小窗口，共 24 张 |

截图自动检查结果保存在 [native-0.2.0.json](validation/native-0.2.0.json)。帧缓冲共 61 张，逻辑尺寸为 1220 × 820 和 900 × 600，在本机 150% DPI 下输出为 1830 × 1230 和 1350 × 900 像素。仓库保存了 [日间概览](screenshots/dashboard.png)、[夜间概览](screenshots/dashboard-dark.png)、[OCS 接入](screenshots/ocs.png) 和 [本地题库](screenshots/questions.png) 的代表截图。

原生截图模式向应用注入本地鼠标位置与焦点输入，不移动系统鼠标，不抢占系统前台焦点。键盘路径另有 Rust 按键测试；直接设置焦点的截图只验证动效终态。测试使用独立演示数据库和临时回环服务；AI 解析测试使用本地模拟响应，未调用真实付费模型，也未修改用户浏览器扩展权限。

已修复验证中发现的回归：图标内部错峰与轻转丢失、按压反馈丢失、侧栏首尾键盘导航和聚焦说明缺失，以及说明状态更新时重复获取界面锁的问题。
