# v0.2.1 · Rust 原生版 / WebView 版

本次同时提供 Windows x64 的两个独立 EXE，使用相同 Rust 业务模块和题库数据。

| 文件 | 适合的使用方式 |
| --- | --- |
| `ai2tiku-native-windows-x64.exe` | Rust + egui/eframe 原生界面；默认折叠侧栏、连续火箭尾焰与统一控件反馈；不需要 WebView2 |
| `ai2tiku-webview-windows-x64.exe` | 保留 Vue + Tauri 界面；需要 Windows WebView2 Runtime |
| `SHA256SUMS.txt` | 两个 EXE 的 SHA-256 校验值，另提供每个文件的 `.sha256` |

## Rust 原生版

- 八个页面迁移为 Rust 原生窗口，采用黑白日夜主题、淡墨山形与毛笔无限标志。
- 菜单每次启动默认显示图标，点击顶部按钮展开或收起；Logo 和图标保持对齐，支持键盘导航及页面提示。
- 火箭保持竖直缓升，尾焰采用连续双层喷流和 72 个细颗粒，向下加速扩散；优化重绘和背景计算，支持减少动态效果。
- 按钮、输入框与下拉控件统一高度和圆角，补齐悬停、按下、焦点与手型反馈；禁用控件保持静态。

## 两版共有的业务修复

- 自动答题采用题干精确匹配，完整核对题型和选项，防止相反题干复用答案。
- 部署和 OCS 接入改为复制完整 JSON，补齐 Edge 用户脚本权限引导；模型状态使用后端实际选择规则。
- 更换端口先绑定新地址，失败保留原服务和配置；服务未启动时禁止复制无效接入地址。
- 保存供应商和模型时校验地址与归属，防止迟到的模型列表重新写入已删除供应商。

WebView 版保留此前的 Vue 界面及黑白水墨视觉；本轮新增的折叠菜单、密集尾焰与控件反馈属于 Rust 原生版。

## 验证与升级

- Rust 原生版：38 项测试通过；71 张原生窗口截图覆盖两种侧栏、日夜、小窗口及弹窗。
- 火箭在本机 240Hz 环境的两次采样平均约 240 fps，95 分位帧间隔低于 4.24ms；帧率受硬件环境影响。
- WebView 版 Vue 生产构建及 26 项兼容入口 Rust 测试通过；GitHub 发布流程分别测试、编译两个版本，全部成功后统一上传。
- 未调用真实付费模型；OCS 浏览器接入仍需在实际课程中搜题核验。

请先退出正在运行的旧版，再选择其中一个 EXE 启动。两版继续读取 `%APPDATA%/com.ai2tiku.app/ai2tiku.db`，不要同时运行并占用相同端口。

完整更新见仓库 `CHANGELOG.md`；原生动效验证见 `docs/native-validation-0.2.1.md`。
