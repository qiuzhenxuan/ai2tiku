# v0.2.2 · WebView 主版本

本次以 Vue + Tauri / WebView2 作为默认桌面界面，将 0.2.1 的交互完善同步到 WebView。Windows x64 下载文件为 `ai2tiku-webview-windows-x64.exe`，同时提供 `.sha256` 和 `SHA256SUMS.txt`。

- 关闭页面、表单、弹窗和 Windows WebView2 的默认右键菜单，保留键盘复制、粘贴与编辑方式。
- 菜单默认仅显示图标，点击顶部按钮展开、收起文字菜单；Logo 和图标保持对齐，支持键盘导航与页面提示。
- 火箭竖直缓升，尾焰使用连续双层喷流和 72 个细颗粒向下扩散；闲置暂停，系统减少动态效果时关闭。
- 主次按钮、输入框与下拉框补齐悬停、按下和焦点反馈；常规单行控件统一 34px 高，图标按钮保持方形。
- 修正直接 Cargo 发布时的资源嵌入开关，Release 内置生产界面，不需要启动本地开发服务器。

保留已有精确题库匹配、答案校验、完整 OCS JSON、Edge 权限引导和端口切换回滚等业务修复。Rust 原生试验实现仍在源码中，默认不编译、不发布。

升级前请退出旧版，启动此 EXE 即可继续读取 `%APPDATA%/com.ai2tiku.app/ai2tiku.db`。Windows 需要 WebView2 Runtime。

已完成前端生产构建、26 项 Rust 测试以及 65 张 Edge 前端截图和交互回归；也在独立数据目录启动了真正的 Tauri/WebView2 Release，核对侧栏、右键、文字编辑和尾焰。未调用真实付费模型；真实课程中的 OCS 接入仍需实际搜题核验。详细范围见仓库 `docs/webview-validation-0.2.2.md`。
