# v0.2.3 · WebView 侧栏过渡完善

本次补齐菜单展开和收起的动画，继续使用 WebView 主版本。

- 侧栏宽度在 72px 与 200px 之间进行约 240ms 平滑过渡，主内容区同步调整。
- 菜单文字和品牌说明渐显、渐隐，八个导航图标保持原位。
- 快速连续点击可从当前宽度反向收起，不跳宽、不越界。
- 系统开启减少动态效果时直接切换。

保留 v0.2.2 的右键菜单修复、连续火箭尾焰、控件反馈、统一尺寸和全部 Rust 业务修复。

已逐帧检查展开、收起与快速反向的中间状态，并完成八页、两种主题、两种侧栏及两种尺寸的生产前端回归。EXE 内嵌生产界面资源，无需启动开发服务器。升级前先退出旧版，默认沿用原数据库。
