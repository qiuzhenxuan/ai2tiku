# v0.2.4 · 侧栏切换方向引导

WebView 主版本补充展开按钮的悬停与键盘聚焦动效：

- 菜单折叠时，箭头向右轻推，提示展开。
- 菜单展开时，箭头向左轻推，提示收起。
- 图标内部平滑运动，按钮和导航图标保持对齐；失去悬停和键盘焦点后复位。
- 系统减少动态效果时保留颜色反馈，不产生位移。

继续包含侧栏平滑展开 / 收起、连续火箭尾焰、控件反馈及右键菜单修复。EXE 内嵌生产界面，无需启动开发服务器。升级前先退出旧版，默认沿用原数据库。

下载 `ai2tiku-webview-windows-x64.exe`，校验值见 `.sha256` 或 `SHA256SUMS.txt`。详细验证记录见仓库 `docs/webview-validation-0.2.4.md`。
