# v0.2.5 · 题库迁移、失败追踪与诊断

- 完整记录已完成搜题请求的成功或失败状态、原因、题型、完整选项、耗时和已返回用量；补充成功率与失败次数。
- 题库 JSON 备份与导出、导入预览、保留原答案的合并导入，以及整库恢复。恢复前自动备份，校验或写入失败时保持原题库。
- 概览、答题记录、统计和题库随数据变化自动刷新；后台暂停，返回窗口刷新，断连后重试。
- 概览和设置提供一键诊断；默认只检查本地与配置，模型实际调用需额外确认可能产生费用。
- 删除、清空和恢复统一使用应用内确认框；点击题干打开长题详情抽屉，完整查看选项、答案、失败原因与用量。
- 保留折叠侧栏、方向引导、火箭连续尾焰、控件反馈和浏览器右键菜单修复。

下载 `ai2tiku-webview-windows-x64.exe`，升级前先退出旧版。默认沿用原数据库，首次运行自动升级记录结构。旧版已经遗漏的失败记录无法补回；备份仅覆盖题库，不包含 API Key 或应用配置。

使用说明见仓库 `docs/data-tools.md`，验证范围见 `docs/webview-validation-0.2.5.md`。附件同时提供 EXE 校验值与 `SHA256SUMS.txt`。
