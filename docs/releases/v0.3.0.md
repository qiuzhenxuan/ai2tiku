# v0.3.0 · 前端重构、接入向导与毛玻璃视觉

- 页面从 8 个合并为 6 个：首页、接入向导、AI 模型、题库、记录与统计、设置；侧栏按「开始使用 / 数据 / 系统」分组，默认展开、窄窗口自动收起，旧地址自动跳转。
- 首页显示接入进度清单，能自动检测的步骤自动打勾，完成后自动收起；指标卡精简为 4 张并加入 14 天趋势。
- 一键部署、OCS 配置与链路自测合并为五步接入向导，配置模型一步可直接选厂商填 Key；OCS 版本只在需要时从 GitHub 获取，失败不再弹窗，可直接前往 Releases 安装。
- AI 模型页按供应商卡片展示，模型列在卡片内，一键设为默认；答题记录与统计合并为标签页，记录可按成功 / 失败筛选。
- 设置页分组展示，修改后才出现保存条，支持撤销、离开提醒与 Ctrl+S；服务开关统一到顶栏，各页状态一致。
- 毛玻璃视觉：半透明材质、8pt 间距、统一的同心圆角，开关跟随强调色；最小窗口 900×600 下布局与对齐完整适配。
- 侧栏选中项滑动指示、悬停提示延迟弹出且文字清晰，展开收起时图标位置不晃动，所有图标对齐同一中线；Ctrl+1…6 快速切换页面。
- 修复折线图数据加载后不重绘、切换页面不回到顶部、侧栏提示被内容区遮挡等问题。
- 彩蛋：连续点击设置齿轮试试。
