# 0.2.3 侧栏过渡验证

2026-10-23，在 WebView 主版本上补充侧栏宽度、品牌说明和菜单文字过渡；保留右键、尾焰及控件修复。

- 侧栏宽度 72px ↔ 200px，过渡约 240ms，文字渐显 / 渐隐；展开和收起过程中各图标原点保持不变。
- Edge 生产前端逐帧采集展开、收起及 80ms 后反向收起。三组各 106–107 帧，分别检测到 49、48、51 个中间宽度帧，最终宽度正确，无越界。
- 65 张截图和交互检查通过，继续覆盖八页、两种主题、两种侧栏和两种尺寸，以及按钮高度、右键、编辑快捷键、键盘导航、尾焰与减少动态效果。
- 真实 Tauri / Windows WebView2 Release 通过独立数据目录启动，展开过程中记录 45 个中间宽度帧；右键、文字编辑、侧栏切换与 72 个尾焰颗粒检查通过。
- Edge 与真实桌面窗体的动画回调间隔中位数约 4.2ms、95 分位约 4.3ms，采样环境为本机 240Hz 显示器，不代表其他硬件的保证帧率。
- 系统减少动态效果时，侧栏过渡时长为 0，尾焰隐藏且火箭不位移。

前端构建、26 项 Rust 测试和嵌入生产资源的 Release 编译通过。未调用真实付费模型，也未修改用户数据库。原生 Rust 试验界面未参与默认构建。

报告：[前端摘要](validation/webview-0.2.3.json)、[真实桌面窗口](validation/webview-desktop-0.2.3.json)。完整帧与布局数据可用 `scripts/check-webview.cjs` 重现生成，桌面验证脚本为 `scripts/check-desktop-webview.cjs`。
