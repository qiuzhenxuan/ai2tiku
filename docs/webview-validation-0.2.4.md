# 0.2.4 侧栏方向引导验证

2026-10-23，在 WebView 主版本上为侧栏切换图标补充方向引导，保留 0.2.3 的宽度和文字过渡。

- 折叠时悬停箭头向右移动 3px，展开时向左移动 3px；分隔线同向移动 1px。约 300ms 平滑过渡，按钮外框尺寸保持不变。
- 检查鼠标移开复位和键盘聚焦方向提示。鼠标移开但仍有键盘焦点时，保留聚焦提示；两者都离开后复位。
- 系统减少动态效果时图标无位移，侧栏直接切换，火箭尾焰隐藏。
- Edge 生产前端回归通过，共 65 张截图，覆盖八页、两种主题、两种侧栏和两种尺寸；右键、编辑快捷键、34px 控件、键盘导航与 72 个尾焰颗粒检查通过。
- 展开、收起及 80ms 后快速反向三组逐帧检查，各记录 107 帧、49 个中间宽度帧；图标原点不变，最终宽度正确，无越界。
- 实际 Windows Tauri / WebView2 Release 通过独立数据目录启动，方向提示及移开复位通过；展开过程记录 49 个中间宽度帧。
- 本机 240Hz 环境中，真实窗口采集 481 个动画回调，帧间隔中位数约 4.2ms、95 分位约 4.3ms；这是本机采样，不代表其他硬件的保证帧率。

前端生产构建、26 项 Rust 测试、Rust 格式检查及内嵌生产资源的 Release 编译通过。未调用真实付费模型，未修改用户数据库。

报告：[前端摘要](validation/webview-0.2.4.json)、[实际桌面窗口](validation/webview-desktop-0.2.4.json)。可用 `scripts/check-webview.cjs` 和 `scripts/check-desktop-webview.cjs` 重现检查。
