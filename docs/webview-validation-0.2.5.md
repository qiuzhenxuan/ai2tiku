# 0.2.5 数据工具与交互验证

2026-10-23，WebView 主版本新增失败追踪、题库迁移、实时更新、诊断与详情交互。

## 后端

44 项 Rust 单元与集成测试通过，包括原有答案匹配、解析和服务生命周期测试，以及：

- 旧记录结构兼容迁移与重复启动；空答案历史记录标记为失败，不丢失历史行。
- 空题目、关闭 AI、无可用模型、HTTP/网络错误和无效请求均留下失败记录；已返回的重试 Token 合并，未通过校验的答案不入缓存。
- 有效答案遇到记录写入失败时仍可返回，同时明确提示保存失败。
- JSON 备份恢复题目与元数据，不包含供应商密钥或请求记录；合并导入保留已有答案。
- 单选、多选和文本选项答案按实际选项内容比较，正确识别乱序重复与冲突。
- 非法文件、过期预览、恢复写入失败和备份失败均不会造成部分替换或数据丢失；恢复前备份可用于再次恢复。
- 默认诊断实际验证本地 HTTP 服务但不调用模型；模拟模型诊断报告用量且不污染题库、答题记录或统计。

前端生产构建、Rust 格式检查与 WebView Release 编译通过；保留的可选原生实现也通过 `cargo check`。

## 前端

- Edge 无界面生产前端回归共 75 张截图：八页 × 两主题 × 两种侧栏 × 两尺寸的 64 张布局截图、火箭悬停，以及 10 张新增数据工具截图。
- 检查 34px 控件、侧栏展开/收起与快速反向、方向提示、图标对齐、72 个尾焰颗粒、减少动态效果、右键与文字编辑快捷键。
- 实时更新检查包括数据版本变化、版本不变时不重复查询、隐藏窗口暂停，以及读数据失败后重试同一版本。
- 长题抽屉完整显示题干、所有选项与失败原因，支持小窗口、日夜主题、滚动、Esc、Tab 焦点约束与焦点返回。
- 应用内确认框默认聚焦取消；检查取消不写入、嵌套恢复确认、无效导入禁用，以及恢复后的备份路径展示。
- 默认诊断不发送模型调用；模型调用检查取消时不执行，确认后才执行。

报告：[基础界面摘要](validation/webview-0.2.5.json)、[新增功能交互](validation/webview-data-0.2.5.json)。可用 `scripts/check-webview.cjs` 与 `scripts/check-data-features.cjs` 重现，测试使用隔离 IPC 数据，不访问用户数据库、不调用真实付费模型。

测试截图为临时文件，脚本默认在结束时清理，仅保留 JSON 检查报告。需要专项视觉核对时可显式设置 `KEEP_TEST_SCREENSHOTS=1` 保留本次截图，核对后清理。仓库只保留文档实际引用的代表截图。

## 验证边界

本轮桌面 EXE 已实际打开题目抽屉并通过 Rust IPC 生成题库 JSON；没有完成系统文件选择框的端到端自动保存和恢复验证。最终自动化不再启动桌面窗口或系统文件框，文件内容、导入事务及回滚由 Rust 测试验证，交互由无界面浏览器验证。真实供应商调用、浏览器扩展内部状态和其他硬件上的帧率未验证。旧版遗漏的失败记录无法追补，数据库本身无法写入时只能返回保存失败提示。
